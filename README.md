# Space Blast 84

8-битный космический шутер в духе Space Impact с Nokia 3310. Игра идёт на экране лампового телевизора «Галактика-84».

**Играть:** https://alejandrotelegin1993.github.io/space-blast/

## Управление

| Клавиша | Действие |
|---|---|
| ← ↑ ↓ → / WASD | полёт |
| Пробел | огонь |
| Enter | старт |
| Tab | пауза |
| C | палитра: экран Nokia или цвета NES |
| M | звук |

Ручки на корпусе тоже работают: «ЦВЕТ» меняет палитру, «ЗВУК» выключает звук, кнопка «ВКЛ» гасит экран.

## Что внутри

Один файл `index.html` на чистом JavaScript и canvas, без зависимостей и сборки. Картинка рисуется в разрешении 168×96 и растягивается ×4 без сглаживания. Эффекты кинескопа (полоски развёртки, затемнение по краям, мерцание) сделаны на CSS.

Чтобы запустить локально, открой `index.html` в браузере.
